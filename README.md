## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ikkti/1.git
```

Go to the project directory:

```bash
cd 1
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
